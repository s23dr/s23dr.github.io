## What this is

A static archive site for the S23DR (Structured Semantic 3D Reconstruction) CVPR workshop competition, hosted on GitHub Pages. No build step, no framework — raw HTML/CSS/JS.

## Regenerating leaderboard data

Year-specific build scripts read raw competition data from a hardcoded local path (not in the repo):

```bash
python3 build_data.py       # 2024 → 2024/data/leaderboard.json  (source: S23DR_2024_ds)
python3 build_data_2025.py  # 2025 → 2025/data/leaderboard.json  (source: S23DR2025_ds)
```

Both source dirs live at `/Users/dmytromishkin/dev/old_hf_s23dr_prev_years/`. After regenerating, commit the JSON file.

**Key metric difference:** 2024 uses WED2 (lower is better, sorted ascending). 2025 uses HSS mean (higher is better, sorted descending). This affects both the Python sort and the JS sort in `leaderboard.js`.

## Previewing locally

Leaderboard and overview pages use `fetch()` for JSON/Markdown, so they need a local server (not `file://`):

```bash
python3 -m http.server 8080
```

## Architecture

```
index.html                  # Root landing page — links to year sub-sites (newest first)
build_data.py               # Generates 2024/data/leaderboard.json from S23DR_2024_ds
build_data_2025.py          # Generates 2025/data/leaderboard.json from S23DR2025_ds
2024/                       # Archived 2024 site (metric: WED2, lower is better)
2025/                       # 2025 site (metric: HSS mean, higher is better)
  index.html                # Overview — fetches content/competition_desc.md
  dataset.html              # Dataset — fetches content/dataset_desc.md
  rules.html                # Rules — fetches content/rules.md
  leaderboard.html          # Leaderboard shell (10 score columns + comment)
  solutions.html            # Top-5 solutions with writeup links (add PDFs to writeups/)
  prizes.html               # Prize table with winners and affiliations
  css/style.css             # Shared styles (identical to 2024/)
  js/nav.js                 # Highlights active nav link based on URL filename
  js/leaderboard.js         # Fetches leaderboard.json, renders, handles public/private tabs
  content/                  # Markdown rendered at runtime by marked.js (CDN)
  data/leaderboard.json     # Generated by build_data_2025.py
  writeups/                 # PDF writeups — drop files here, link from solutions.html
```

Key data flow (both years): build script reads `teams.json` + per-team `submission_info/*.json` → picks best **selected** submission per team (falls back to best overall if none selected) → sorts → writes `leaderboard.json`. JS re-sorts client-side when switching public/private tabs.

To add a new competition year: create `YEAR/` mirroring the 2025 structure, write a new `build_data_YEAR.py`, and add a link in `index.html`.
